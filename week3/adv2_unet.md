# 심화 ② 모델 비교: YOLOv8s-Seg vs U-Net

- U-Net: resnet34 인코더(ImageNet), 960×544, BCE + Dice, 20 epoch 학습(조기 종료 patience 10), best = epoch 10 (검증 mIoU 0.500)
- 학습 설정: AdamW lr 1e-4 + 기울기 클리핑 · 배치 합산 Dice · 증강 약함(좌우 뒤집기 · 밝기)
- 같은 분할(2주차) · 같은 테스트셋. 임계값은 두 모델 모두 검증셋에서 고르고 테스트에 고정 적용
- U-Net 영상 점수 = 확률 0.5 이상 픽셀의 면적 비율 (확률 최댓값은 포화돼 임계값이 의미 없어 비교용 행으로만 둠)

| 지표 | YOLOv8s-Seg | U-Net |
|---|---:|---:|
| 파라미터 수 | 11.8M | 24.4M |
| 1장 추론 시간 (GPU, 전처리 포함) | 26 ms | 46 ms |
| 출력 | 인스턴스(마스크 + 신뢰도) | 픽셀별 클래스 확률 |
| 선택 임계값 (crack / efflo / spall; U-Net = 면적 비율) | 0.2 / 0.02 / 0.06 | 1e-06 / 0.01 / 0.003 |
| 테스트 ON/OFF F1 crack (FP / FN) | 0.800 (2 / 3) | 0.963 (1 / 0) |
| 테스트 ON/OFF F1 efflorescence (FP / FN) | 0.963 (1 / 0) | 1.000 (0 / 0) |
| 테스트 ON/OFF F1 spall_detach (FP / FN) | 1.000 (0 / 0) | 0.857 (2 / 2) |
| 테스트 macro F1 | 0.921 | 0.940 |
| (비교용) U-Net 확률 최댓값 점수: 임계값 · macro F1 | - | 0.1 / 0.99 / 0.9 · 0.931 |

- 한 번씩만 학습한 비교라 시드 변동(⑤)보다 작은 차이는 의미를 두기 어렵다. U-Net은 발산 · 붕괴 때문에 손실 · 학습률을 두 번 고쳤고(runs/_unet_*), 증강 두 가지(unet · unet_aug) 중 최종은 검증 mIoU로 고른다.
